HTML & CSS Internship Portfolio 

This project follows the guide's main requirements:
- Separate index.html and style.css files
- HTML5 structure and semantic header, nav, main, section, article and footer tags
- Home, About, Skills, Projects and Contact sections
- Six skill labels and two project cards
- Navigation links that jump to each section
- Flexbox layout, hover/focus styling and a mobile media query
- A profile illustration in images/profile.svg with alternative text
- Desktop and mobile screenshots in screenshots/
